## 实际改动

- `ProfileBarView` 将 SSO、查询身份和区域分组，Profile 吸收剩余宽度，区域在窄窗口换行；验证次行显示账号与稳定角色名称。Session 菜单明确左对齐，未验证 Profile 的区域仍禁用。
- `EC2ListView` 提供全部／运行中／已停止及其他实际状态筛选，数量只使用已加载列表；每行展示名称、ID、私有 IP 和运行状态，机型继续参与搜索。
- `EC2DetailHeaderView` 突出 Connect，复制／收藏／关系作为次操作，保留当前范围校验与原有关系面板接线；窄详情操作换行。
- `EC2OverviewSummaryView` 在 680 pt 边界切换两列／单列；常用字段分为四区，其他基础字段默认折叠，标签独立显示。存储／安全摘要严格区分未读、加载、失败、空结果，并只通过已有页签入口读取。
- 移除 EC2 状态检查展示、筛选、调用链及无消费者的服务／模型／专属词条；保留基本 Status 页、SSM 身份校验、目标健康、ASG 健康配置和 AWS Health。
- 同步 `DESIGN.md`、双语 README、原生组件截图和当前进度；没有新增依赖。
