# 审查确认问题修复

## 目标与范围

基于 `5da3211` 的逐项审查结论，用户授权修复必要问题。优先消除可恢复请求导致永久失效、分页无法自行终止和刷新任务互相取消的问题，同时补齐范围校验、AMI 容错、上传孤儿副本清理、SSM 旧插件保护与 SNS 视觉一致性。保留显式 Profile、同组凭据验证、服务按需查询和真实 AWS 操作边界。

本轮不修改已被证伪的 Lambda 模型 ID 或客户端关闭链，不将 Health 的可用事件机械截断为开始时间近 90 天，不新增依赖。Cost 缓存现有范围／代次隔离保留。全局样板去重、主壳与详情文件拆分作为独立重构，不混入本批缺陷修复。

## 任务与所有权

所有参与者保留他人改动，不并行运行 SwiftPM，不提交或执行真实 AWS 请求。主线统一维护本地化、设计、文档、构建与提交。

- A：`IdentityBoundCredentialProvider.swift`、对应凭据／Provider 测试，以及 `AWSServiceProvider.swift` 中确定角色不匹配的错误分类。临时失败保留绑定并有界冷却，只有已确认身份不匹配永久失效；并发候选、取消与恢复不能放行未验证凭据。
- B：EC2 DataLoader／ViewModel／列表与对应测试。分页预算、token 循环防护、AMI 批次与无效 ID 隔离、安全合并重复响应；同范围刷新失败保留旧数据并标记 stale，范围变化仍清空。补 Soto 响应映射测试。
- C：Lambda ReadService／ViewModel／列表与对应测试，必要的响应 Mapper，以及策略模型的 Sendable 声明。分页防护、基础清单刷新降级、同步策略解析离开主线程；保留摘要局部降级与既有 ID。
- D：S3 ViewModel 与对应测试。桶列表与对象加载分别管理任务，async 入口纳入取消；同范围刷新保留仍存在的选择与浏览／详情，首次加载仍沿用既有首桶选择语义。
- E：收藏导航、对应测试，必要的 Route53／ELB／安全组范围只读访问。所有分支核对当前 Profile、账号、主体、路径和适用区域；拒绝 loading／stale／错误清单，Route53 保留全局区域语义。EC2／Lambda／S3 的访问接口由 B／C／D 提供。
- F：上传私有副本与清理辅助、SSM 脚本与对应模拟测试。上传目录通过私有标记和跨进程锁识别活动任务；只清理验证过的孤儿副本，不删除未知旧目录、活动上传或下载恢复文件。SSM 在取得凭据前拒绝不能保障环境传参的 CLI／插件版本。
- 主线：先更新 `DESIGN.md`，再收敛 SNS 装饰样式；接线启动清理与桶消失时退出浏览，补齐本地化和当前使用说明，整合验证与独立复核。

## 验证与验收

- 分页：正常、空页、空 token、重复／循环 token、页预算、取消、错误与迟到回调；失败不能伪装完整成功。
- 凭据：临时获取／验证失败后恢复、冷却合并、取消不永久卡住、错账号／稳定主体持续拒绝，未验证候选零业务调用，错误不包含凭据。
- 刷新：同范围保留旧列表／选择并明确 stale，跨范围立即清空；收藏拒绝错误范围和不完整清单；S3 浏览与桶刷新并行不互相取消，删除当前桶清浏览。
- 文件与进程：使用任务临时目录、假 CLI／插件和模拟传输；验证活动锁、孤儿、符号链接、陌生目录、版本异常／旧版本及正常取消，不对真实 S3 写入或建立 SSM 会话。
- 视觉：SNS 使用语义色、轻分隔、单色线性符号，核对中英／深浅色原生模拟渲染。
- 主线运行严格构建、全量离线测试、双语资源校验、Harness task 与差异检查；独立复核实际改动和日志。源码验证不代替真实 AWS、完整窗口、Intel 或 macOS 13 实机验收。

## 实际改动

- EC2／Lambda 分页统一采用 1,000 页预算，拒绝重复、循环和全空白 token，空字符串视为结束，取消或不完整结果不发布半份成功。EC2 的 AMI 请求每批最多 100 个 ID，仅对 `InvalidAMIID.NotFound` 二分隔离，重复响应安全保留首个名称。
- 凭据临时获取／验证失败不再永久撤销绑定；使用单调时钟执行 1、2、4、8、16、30 秒上限冷却，成功后重置。并发相同候选合并验证，只有确定账号／稳定主体／配置角色不匹配时永久失效，取消和脱敏错误分类保留。
- EC2／Lambda 同范围基础清单刷新失败保留旧列表、选择和已加载详情，显示数据可能过期；首次失败和跨范围重置仍为空。Lambda 策略 JSON 的同步解析移出主线程，SDK 响应映射提取为可直接测试的本地转换，不改变 ARN／模型 ID。
- S3 桶列表、对象浏览分别管理任务、错误与取消；刷新保留仍存在的当前桶、详情、前缀和对象列表。async 对象入口纳入任务管理，桶消失时清理浏览。首次清单加载保留既有首桶选择语义。
- 收藏解析对所有旧服务分支核对当前已验证范围、完整 Profile、账号、稳定主体、配置路径和适用区域，拒绝 loading／stale／错误清单；Route53 保留全局区域语义。拒绝 S3 目标时仅清选择和浏览，不取消桶刷新。
- 上传副本使用私有标记及跨进程排他锁，启动在后台有界扫描可识别孤儿目录；清理绑定打开的目录，将候选内容原子隔离并再次校验 inode／所有权／权限／链接数。竞争替换文件恢复或保留，后续启动也不删除；未知旧目录、活动上传和下载恢复副本不在清理范围内。
- SSM 在导出凭据前要求 AWS CLI v2 ≥ 2.37.9、Session Manager 插件 v1 > 1.2.497.0，拒绝未知格式／主版本，阻止旧实现回退为 argv 传递敏感会话响应。凭据仍只在内存环境中供同组 STS／SSM 调用。
- SNS 关系卡片改用单色 SF Symbols、系统语义表面和 1 pt 边线，复用摘要区间距／圆角，去掉渐变、装饰投影和节点彩色背景。同步双语提示、使用说明与设计规范。
